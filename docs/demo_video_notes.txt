LIKELY QUESTIONS
Is any of this real? The data is. The brand, email, signatures and payments are simulated, and labelled on screen.
Why not instant? Real lookups take time. A setting also slows steps so viewers can follow, and the page says so.
Where is the AI? Code makes decisions, so the same case gets the same answer. An optional LLM only reads messy text. It hasn't been run live yet.
Whose side are you on? Neither. One published rule, private limits, and a disclosed 5% fee from each side, only on closed deals.
Can a side game its limit? Yes, in theory. No efficient mechanism can prevent it. We say so in docs/proofs.txt.
What's not secure yet? There's no sign-in, so this isn't ready for real money. review.md lists the gaps.
